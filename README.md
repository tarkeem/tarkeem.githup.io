# Tarek Mohamed — Software Developer Portfolio

Responsive HTML, CSS, and vanilla JavaScript portfolio based on the supplied CV.

## Included
- Profile and professional summary.
- Projects: Kalimaty, Readabic, Hudai, eMarefa AI Search, Saudi Embassy QR Code Scanner, Taxi Landskrona, Ultranote, MACIDP, and Image Filter.
- Clickable project cards open detailed views with role, contributions, technologies, and available links.
- Filters for mobile, web/backend, and Android projects.
- Dedicated Backend Experience section and Web / Backend project-filter entries for Readabic (Node.js/Express) and Kalimaty (Laravel, feature enhancements, and store payment gateway integrations).
- Skills, about, and contact sections.
- Locally stored SVG project artwork.

## Before publishing
- Replace the generic GitHub and LinkedIn profile URLs in `index.html` with your real profile URLs.
- Add public links for other apps or repositories in the relevant project's `links` entry in `script.js`.
- Replace sample SVG artwork in `assets/projects/` with real app screenshots when available.
- Check every description and role before publishing.

## Run locally
Open `index.html` in a browser. No dependencies or build tools are required.

## Publish with GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload all contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Visit `https://YOUR-USERNAME.github.io` after deployment completes.
